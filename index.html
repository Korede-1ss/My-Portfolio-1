About Me

About Me

I'm a front-end developer with a growing passion for building clean, intentional digital experiences and understanding how systems work behind the scenes.

My interest in coding started with simple HTML and CSS, and it grew from there. I enjoy taking an idea and turning it into something usable, polished, and easy to interact with. That moment when a blank canvas becomes a working design is still the part I love most.

I’m currently sharpening my skills through structured learning and hands-on practice, while also exploring cybersecurity to deepen my understanding of web security, problem-solving, and digital defense. I’m especially drawn to the overlap between design, functionality, and secure thinking.

LEARN BY SEEING

A tiny animation lab

Small CSS animations, shown in motion with the code that creates them. Pick an effect, watch it, then try the snippet in your own project.

01 / ENTRANCE

Fade & rise

LIVE PREVIEW
Hello, motion.
CSS 
.fade-in {
  animation: fade-up 1.8s ease-in-out infinite alternate;
}

@keyframes fade-up {
  from { opacity: .35; transform: translateY(12px); }
  to   { opacity: 1; transform: translateY(0); }
}

Animate opacity and position for a soft entrance.

02 / FEEDBACK

Soft pulse

LIVE PREVIEW
Hover-worthy button
CSS 
.pulse {
  animation: pulse 1.6s ease-in-out infinite;
}

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.06); }
}

A gentle scale can draw attention without shouting.

03 / LOADING

Orbiting dot

LIVE PREVIEW
CSS 
.orbit {
  animation: spin 2.4s linear infinite;
}

@keyframes spin {
  to { transform: rotate(1turn); }
}

Combine a rotating wrapper with an offset child.
